# 《神经科学原理》Part II：神经元的细胞与分子生物学

> **定位**：理解电信号如何在单个神经元内产生。Part III 突触传递的物理前提。
> 
> **核心命题**：神经元如何利用离子浓度梯度和膜通透性产生静息电位、动作电位，并完成细胞内物质运输？

---

## 一、章节定位与学习目标

### 1.1 为什么这一部分重要

- 如果不懂膜电位和动作电位，就无法理解突触传递、神经编码和脑电信号。
- 这是神经科学中最“物理”的部分，也是后续所有机制的底层。
- 动作电位的“全或无”特性是数字式神经编码的基础。

### 1.2 阅读目标

1. 掌握静息电位的产生机制（Na⁺/K⁺泵、K⁺漏通道、Donnan 平衡）。
2. 理解动作电位的离子基础（电压门控 Na⁺、K⁺通道）。
3. 掌握动作电位的传导、髓鞘化和跳跃传导。
4. 了解神经元细胞骨架、轴突运输和神经营养因子。
5. 将这些机制与神经编码、信号传递建立联系。

## 二、离子通道与膜电位

### 2.1 神经元膜的电学特性

- 细胞膜是**脂质双分子层**，对离子不通透。
- 离子通道是跨膜蛋白，提供选择性离子通透路径。
- 膜电位 = 膜内外电荷分离形成的电压差。

### 2.2 静息电位

- 典型神经元静息电位：约 **-65 mV**（内负外正）。
- 主要由 **K⁺漏通道** 决定，因为静息时膜对 K⁺通透性最高。
- **Na⁺/K⁺-ATPase** 维持浓度梯度：
  - 每消耗 1 个 ATP，泵出 3 个 Na⁺，泵入 2 个 K⁺。
  - 直接贡献少量膜电位（约 -3 至 -5 mV）。

### 2.3 Nernst 方程与平衡电位

对于单一离子：

```
E_ion = (RT/zF) × ln([ion]_out / [ion]_in)
```

近似值（37°C）：

| 离子 | 细胞外浓度 | 细胞内浓度 | 平衡电位 |
|------|----------|----------|---------|
| K⁺ | 5 mM | 140 mM | -90 mV |
| Na⁺ | 145 mM | 12 mM | +60 mV |
| Cl⁻ | 110 mM | 4 mM | -65 mV |
| Ca²⁺ | 2 mM | 0.0001 mM | +120 mV |

### 2.4 Goldman-Hodgkin-Katz 方程

- 实际膜电位由多种离子的相对通透性决定。
- 静息时 K⁺通透性占主导，膜电位接近 E_K。
- 动作电位上升期 Na⁺通透性占主导，膜电位接近 E_Na。

### 2.5 离子通道类型

| 门控机制 | 代表通道               | 激活因素  |
| ---- | ------------------ | ----- |
| 电压门控 | Na_v, K_v, Ca_v    | 膜电位变化 |
| 配体门控 | AMPA, NMDA, GABA_A | 神经递质  |
| 机械门控 | 听觉毛细胞通道            | 机械力   |
| 温度门控 | TRP 通道             | 温度变化  |
| 泄漏通道 | K²P, K_ir          | 持续开放  |

## 三、动作电位

### 3.1 动作电位的阶段

```
静息电位 (-65 mV)
    ↓ 去极化达到阈值 (-55 mV)
快速去极化相（Na⁺内流）→ 峰值 (+40 mV)
    ↓
复极化相（K⁺外流）
    ↓
超极化后电位（K⁺持续外流）
    ↓
回到静息
```

### 3.2 电压门控 Na⁺通道

- 具有**激活门**（快速开放）和**失活门**（快速关闭）。
- 激活速度快（< 1 ms），失活也快。
- 失活状态使膜进入**不应期**：
  - 绝对不应期：无法产生新的动作电位。
  - 相对不应期：需要更强刺激才能触发。

### 3.3 电压门控 K⁺通道

- 激活较慢，负责复极化。
- 某些 K⁺通道（如 I_A, I_h）调节放电模式。

### 3.4 动作电位的“全或无”特性

- 达到阈值就产生完整动作电位，未达阈值则不产生。
- 动作电位幅度不随刺激强度变化。
- 信息编码不依赖幅度，而依赖**频率**和**时间模式**。

### 3.5 动作电位传导

- 动作电位产生后，局部电流使邻近膜去极化达到阈值。
- 传导速度取决于：
  - 轴突直径（越大越快）
  - 髓鞘化程度（有髓鞘更快）

### 3.6 髓鞘化与跳跃传导

| 特征 | 有髓鞘轴突 | 无髓鞘轴突 |
|------|----------|----------|
| 传导速度 | 快（可达 100 m/s） | 慢（约 1 m/s） |
| 能量效率 | 高 | 低 |
| 动作电位位置 | 郎飞结处 | 连续产生 |
| 细胞来源 | 少突胶质细胞/施万细胞 | 无 |

- **跳跃传导（Saltatory Conduction）**：动作电位在郎飞结之间跳跃式传导，大大提高速度并节省能量。
- 脱髓鞘疾病（如多发性硬化）导致传导阻滞或减慢。

## 四、神经元的细胞生物学

### 4.1 细胞骨架

| 成分 | 直径 | 功能 |
|------|------|------|
| 微丝（Actin） | ~7 nm | 树突棘形态、突触可塑性 |
| 微管（Microtubules） | ~25 nm | 轴突运输、细胞形态 |
| 神经丝（Neurofilaments） | ~10 nm | 轴突直径与稳定性 |

### 4.2 轴突运输

| 运输方向 | 速度 | 运输物质 |
|---------|------|---------|
| 顺向快速 | 200-400 mm/天 | 突触小泡、线粒体、膜蛋白 |
| 顺向慢速 | 0.2-8 mm/天 | 细胞骨架蛋白、可溶性蛋白 |
| 逆向快速 | 200-400 mm/天 | 神经营养因子、内吞泡、信号分子 |

- 顺向运输由 **Kinesin** 驱动蛋白完成。
- 逆向运输由 **Dynein** 动力蛋白完成。
- 轴突运输障碍与多种神经退行性疾病相关。

### 4.3 神经营养因子

| 因子              | 主要来源     | 功能              |
| --------------- | -------- | --------------- |
| NGF（神经生长因子）     | 靶组织、胶质细胞 | 感觉/交感神经元存活      |
| BDNF（脑源性神经营养因子） | 皮层、海马    | 突触可塑性、学习记忆、神经发生 |
| NT-3            | 多种组织     | 运动/感觉神经元发育      |
| GDNF            | 胶质细胞     | 多巴胺神经元存活        |
- 神经营养因子通过 Trk 受体（酪氨酸激酶受体）和 p75 受体发挥作用。
- BDNF 在 LTP 中扮演关键角色（见 Part III）。
### 4.4 神经元的代谢需求

- ==神经元高度依赖葡萄糖和氧气。==
- ==动作电位恢复和离子梯度维持消耗大量 ATP。==
- ==脑仅占体重 2%，却消耗约 20% 的能量。==

## 五、神经编码基础
### 5.1 频率编码
- 刺激强度 → 动作电位发放频率。
- 强刺激：高频放电；弱刺激：低频放电。
### 5.2 时间编码
- 动作电位的精确时间也携带信息。
- 听觉系统尤其依赖时间编码处理声音频率。
### 5.3 群体编码
- 单个神经元的信息有限。
- 大量神经元的活动模式共同表征复杂信息。

## 七、与你关心主题的关联映射

### 7.1 “兴奋性”的物理基础

- 神经元的兴奋性取决于：
  - 膜电位与阈值的距离
  - Na⁺通道密度与特性
  - K⁺通道类型
- 杏仁核神经元的高兴奋性使其对威胁信号反应迅速。
- 前额叶神经元的高适应性使其支持复杂计算。

### 7.2 动作电位与信息处理速度

- 粗大有髓鞘轴突（如运动神经元）传导快，适合快速反应。
- 细小无髓鞘纤维（如 C 纤维痛觉）传导慢，但信息持久。
- 大脑通过轴突直径和髓鞘化实现信息传输的“带宽分配”。

### 7.3 BDNF 与认知训练

- BDNF 是运动、学习、睡眠增强认知的重要介质。
- 有氧运动增加 BDNF 表达，促进海马神经发生和突触可塑性。
- 这为“身体训练增强认知防御”提供分子机制。

## 九、记忆卡片（Anki 风格）

**Q：静息电位主要由哪种离子决定？**
A：K⁺。静息时膜对 K⁺通透性最高，膜电位接近 K⁺平衡电位（约 -90 mV），实际静息电位约 -65 mV。

**Q：动作电位的上升支和下降支分别由什么离子流介导？**
A：上升支由 Na⁺快速内流介导；下降支由 K⁺外流介导。

**Q：什么是动作电位的“全或无”特性？**
A：刺激达到阈值则产生完整幅度的动作电位，未达阈值则不产生；动作电位幅度不随刺激强度变化。

**Q：髓鞘如何提高动作电位传导速度？**
A：髓鞘绝缘减少膜电容和离子泄漏，动作电位在郎飞结处再生，形成跳跃传导，速度快且节能。

**Q：顺向和逆向轴突运输分别由什么马达蛋白驱动？**
A：顺向由 Kinesin 驱动；逆向由 Dynein 驱动。
