# 《神经科学原理》Part I：总论（Introduction）

> **定位**：建立神经科学的整体地图。理解大脑与行为的关系、神经系统的解剖框架、神经环路的基本逻辑。
> 
> **核心命题**：为什么说脑是行为的器官？神经系统如何通过不同层级的结构实现从感知到行动的转换？

---

## 一、章节定位与学习目标

### 1.1 为什么从总论开始

- 神经科学是一门高度层次化的学科：从分子 → 细胞 → 环路 → 系统 → 行为。
- Part I 提供“导航图”，帮助后续学习定位每个知识点在哪个层级。
- 理解神经环路的基本逻辑（感觉 → 整合 → 运动）是理解决策、情绪和认知的前提。

### 1.2 阅读目标

1. 理解“脑是行为器官”这一核心命题的实验与临床证据。
2. 掌握神经元的基本结构与功能分区。
3. 理解神经回路的兴奋/抑制平衡原则。
4. 熟悉中枢神经系统与外周神经系统的基本解剖。
5. 建立后续章节学习的空间与概念框架。

## 二、大脑与行为：脑是行为的器官

### 2.1 从脑损伤到功能定位

| 案例/发现              | 说明              | 意义           |
| ------------------ | --------------- | ------------ |
| Phineas Gage（1848） | 前额叶铁棒损伤，人格改变    | 前额叶与性格、决策相关  |
| Broca 失语           | 左额下回损伤导致运动性失语   | 语言功能有特定脑区定位  |
| Wernicke 失语        | 左颞上回后部损伤导致感觉性失语 | 语言理解与表达分离    |
| H.M. 病例            | 双侧海马切除后遗忘症      | 海马对陈述性记忆至关重要 |

### 2.2 神经环路的逻辑

神经系统处理信息的基本模式：

```
感觉输入 → 中间神经元整合 → 运动输出
    ↓           ↓              ↓
  受体       中枢脑区        效应器
（眼耳皮肤） （皮层/皮层下） （肌肉/腺体）
```

- **感觉系统**：将外界物理/化学信号转化为神经信号。
- **整合系统**：对信息进行比较、预测、决策。
- **运动系统**：将神经信号转化为行为。

## 三、神经元的细胞生物学

### 3.1 神经元的典型结构

| 结构                   | 功能               |
| -------------------- | ---------------- |
| 胞体（Soma）             | 代谢中心，含细胞核和大部分细胞器 |
| 树突（Dendrites）        | 接收输入信号，进行局部整合    |
| 轴突（Axon）             | 产生并传导动作电位        |
| 轴突末梢（Axon Terminal）  | 释放神经递质           |
| 树突棘（Dendritic Spine） | 接收兴奋性突触输入，可塑性结构  |

### 3.2 神经元 vs 其他细胞

- 神经元高度特化于**电信号产生与传递**。
- 具有**极性**：信息从树突→胞体→轴突单向流动。
- 出生后一般**不分裂**（少数区域例外，见 Part VII）。
- 依赖**轴突运输**长距离运送物质。

### 3.3 神经元蛋白质合成

- 大部分蛋白在胞体合成，通过轴突/树突运输分布。
- 树突棘局部也有翻译机制，对突触可塑性至关重要。
- 这解释了为什么局部突触变化可以不依赖胞体即时参与。

### 3.4 胶质细胞

| 类型     | 主要功能               |
| ------ | ------------------ |
| 星形胶质细胞 | 支持、血脑屏障、缓冲 K⁺、调节突触 |
| 少突胶质细胞 | 中枢神经系统髓鞘形成         |
| 施万细胞   | 外周神经系统髓鞘形成         |
| 小胶质细胞  | 免疫防御、突触修剪          |
| 室管膜细胞  | 脑脊液循环              |

## 四、神经回路概述

### 4.1 兴奋与抑制

- **兴奋性神经元**：释放谷氨酸，使突触后神经元去极化，增加放电概率。
- **抑制性神经元**：释放 GABA 或甘氨酸，使突触后神经元超极化或分流，降低放电概率。
- 神经环路的功能取决于兴奋/抑制（E/I）平衡。

### 4.2 感觉-整合-运动环路

```
感觉神经元 → 中间神经元网络 → 运动神经元
    ↑                              ↓
  感受器                        效应器
（皮肤/视网膜等）              （肌肉/腺体）
```

- **反射弧**是最简单的神经回路。
- 更复杂的回路涉及皮层、丘脑、基底神经节、小脑等。

### 4.3 前馈、反馈与侧抑制

| 回路类型 | 机制 | 功能 |
|---------|------|------|
| 前馈兴奋 | 感觉神经元→中间神经元→运动神经元 | 快速传递信号 |
| 前馈抑制 | 侧枝激活抑制性中间神经元 | 限制反应范围 |
| 反馈抑制 | 输出神经元激活抑制性中间神经元返回自身 | 防止过度兴奋 |
| 侧抑制 | 相邻神经元相互抑制 | 增强对比度 |

### 4.4 神经调质的作用

- 神经调质（如多巴胺、血清素、乙酰胆碱）改变环路的兴奋性和可塑性。
- 它们不直接传递特定信息，而是设定神经网络的“状态”。
- 例如：去甲肾上腺素设定警觉水平，乙酰胆碱设定注意焦点。

## 五、神经系统解剖

### 5.1 中枢神经系统 vs 外周神经系统

```
神经系统
├── 中枢神经系统（CNS）
│   ├── 脑
│   │   ├── 大脑半球（皮层、基底核、边缘系统）
│   │   ├── 间脑（丘脑、下丘脑）
│   │   ├── 脑干（中脑、脑桥、延髓）
│   │   └── 小脑
│   └── 脊髓
└── 外周神经系统（PNS）
    ├── 躯体神经（控制骨骼肌，传递皮肤感觉）
    └── 自主神经
        ├── 交感神经
        └── 副交感神经
```

### 5.2 脑的大体分区

| 脑区    | 主要功能             |
| ----- | ---------------- |
| 大脑皮层  | 感觉、运动、认知、语言、执行功能 |
| 基底神经节 | 运动控制、习惯形成、决策     |
| 丘脑    | 感觉中继站，皮层信息门户     |
| 下丘脑   | 内稳态、动机、自主神经调控    |
| 杏仁核   | 情绪、恐惧、显著性检测      |
| 海马    | 陈述性记忆、空间导航       |
| 小脑    | 运动协调、运动学习、某些认知功能 |
| 脑干    | 生命基本功能（呼吸、心跳、觉醒） |

### 5.3 大脑皮层的分叶

| 脑叶  | 主要功能              |
| --- | ----------------- |
| 额叶  | 运动控制、执行功能、工作记忆、人格 |
| 顶叶  | 躯体感觉、空间注意、整合      |
| 颞叶  | 听觉、语言、记忆、物体识别     |
| 枕叶  | 视觉加工              |
| 岛叶  | 内感受、情绪、痛觉         |

### 5.4 功能柱与皮层组织

- 皮层垂直方向存在**功能柱**（Functional Column），同一柱内神经元对相似特征反应。
- 水平方向存在**层级组织**（Layer I-VI），不同层接收和发送不同来源的投射。

## 九、记忆卡片（Anki 风格）
**Q：为什么说脑是行为的器官？**
A：脑损伤或刺激可特异性改变行为；神经环路将感觉输入转化为运动输出；所有心理过程都有神经基础。
**Q：神经元的基本结构分区及其功能？**
A：树突接收信号，胞体整合与代谢，轴突传导动作电位，轴突末梢释放递质。
**Q：中枢神经系统与外周神经系统的组成？**
A：CNS 包括脑和脊髓；PNS 包括躯体神经和自主神经（交感/副交感）。
**Q：什么是神经环路中的 E/I 平衡？**
A：兴奋性输入与抑制性输入之间的动态平衡，决定神经元的输出和网络状态。
**Q：大脑皮层的四个主要脑叶及其核心功能？**
A：额叶（执行/运动）、顶叶（感觉/空间）、颞叶（听觉/记忆/语言）、枕叶（视觉）。
