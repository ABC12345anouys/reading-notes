# 《神经科学原理》Part III：突触传递（Synaptic Transmission）

> **定位**：神经元之间的“对话”机制。这是学习、记忆、情绪调节、决策训练的物理基础。
> 
> **核心命题**：电信号到达轴突末梢后，如何通过化学或电的方式跨越突触间隙，引起下一个神经元的反应？这种连接如何被经验重塑？

---

## 一、章节定位与学习目标

### 1.1 为什么这一部分是“核心中的核心”

- 单神经元的电活动（Part II）只是“硬件通电”，真正的信息处理发生在**神经元网络**中。
- 突触是神经网络的基本连接单元，决定了：
  - 信号是兴奋还是抑制
  - 信息传递的强度
  - 连接是否可以被经验修改（可塑性）
- 政治敏感度、信号识别、认知防御本质上都是**突触权重调整**后的行为输出。

### 1.2 阅读目标

1. 理解电突触与化学突触的区别与各自优势。
2. 掌握神经递质释放的分子机制（囊泡、Ca²⁺触发、量子释放）。
3. 区分主要神经递质及其受体的功能特性。
4. 理解细胞内信号转导如何连接短时突触活动与长时基因表达。
5. 掌握 LTP/LTD 的细胞机制，并理解其作为学习记忆基础的地位。

---

## 二、核心概念与术语

### 2.1 突触的基本结构

| 结构 | 位置/组成 | 功能 |
|------|----------|------|
| 突触前末梢 | 轴突末端，含突触小泡 | 储存并释放神经递质 |
| 突触间隙 | 约 20-40 nm 的细胞外间隙 | 递质扩散 |
| 突触后膜 | 树突棘或胞体膜 | 含受体，接收信号 |
| 活性区 | 突触前膜特化区域 | 囊泡锚定与释放位点 |
| 突触后致密区 (PSD) | 突触后膜下方蛋白富集区 | 受体锚定与信号整合 |

### 2.2 电突触 vs 化学突触

| 维度 | 电突触 (Electrical Synapse) | 化学突触 (Chemical Synapse) |
|------|---------------------------|---------------------------|
| 结构基础 | 缝隙连接 (Gap Junction)，由连接蛋白 (Connexin) 构成 | 突触前末梢 + 突触间隙 + 突触后膜 |
| 传递方式 | 离子直接通过缝隙连接流动 | 神经递质释放并扩散 |
| 速度 | 快（几乎无延迟） | 较慢（约 0.5-1 ms 突触延迟） |
| 方向性 | 通常为双向 | 单向（前→后） |
| 可塑性 | 较弱 | 极强，是学习与记忆的基础 |
| 主要分布 | 视网膜、下丘脑、心肌、胶质细胞 | 绝大多数中枢突触 |
| 优势 | 同步化活动、快速反应 | 可放大、可调制、可整合、可塑 |

**关键洞察**：化学突触的“慢”换来了“可计算”。大脑利用化学突触完成信号的加权、门控和可塑性存储。

## 三、神经递质释放机制

### 3.1 突触囊泡生命周期

```
合成/回收 → 转运至末梢 → 锚定在活性区（Docking）
    ↓
Ca²⁺内流 → 触发融合（Priming → Fusion）
    ↓
胞吐释放 → 递质扩散 → 与突触后受体结合
    ↓
囊泡回收（Clathrin 介导的内吞 / Kiss-and-run）
```

### 3.2 Ca²⁺触发的核心作用

- 动作电位到达突触前末梢 → 电压门控 Ca²⁺通道（VGCC）开放 → Ca²⁺快速内流。
- Ca²⁺与突触结合蛋白（Synaptotagmin）结合 → 触发 SNARE 复合体介导的囊泡融合。
- Ca²⁺浓度与释放概率**高度非线性**：释放概率 ∝ [Ca²⁺]⁴，因此动作电位时程的微小变化会显著改变释放量。

### 3.3 量子释放理论

- **量子释放**（Quantal Release）：一个囊泡所含递质作为一个最小单位释放。
- **最小兴奋性突触后电位（mEPSP）**：单个囊泡释放引起的突触后反应。
- **释放概率（Pr）**：动作电位到达时，囊泡实际释放的概率。
- **量子含量（m）**：一次动作电位释放的囊泡平均数，m = n × Pr（n 为可用囊泡数）。

**关键公式**：

```
EPSP 幅度 = 量子含量(m) × 单个量子大小(q)
```

### 3.4 突触传递的可靠性问题

- 中枢突触的释放概率通常不高（0.1-0.5），单个突触传递并不可靠。
- 大脑通过**多个突触汇聚**（Convergence）和**时间整合**来提高信号可靠性。
- 这一点对理解“弱信号检测”很重要：单个线索可能不足以触发反应，但多通道弱信号的整合可以。

## 四、主要神经递质与受体

> 所有情绪、动机、注意、记忆、决策的化学基础都在这里。

### 4.1 快速递质 vs 慢速调质

| 类型   | 作用时间 | 受体位置  | 功能               |
| ---- | ---- | ----- | ---------------- |
| 快速递质 | 毫秒级  | 离子型受体 | 直接改变膜电位          |
| 慢速调质 | 秒至分钟 | 代谢型受体 | 通过第二信使调制兴奋性、基因表达 |

### 4.2 谷氨酸（Glutamate）—— 主要兴奋性递质

| 受体类型        | 亚型               | 离子选择性       | 主要功能                                       |
| ----------- | ---------------- | ----------- | ------------------------------------------ |
| **AMPA**    | GluA1-A4         | Na⁺/K⁺      | 介导大多数快速兴奋性突触传递                             |
| **NMDA**    | GluN1 + GluN2A-D | Na⁺/K⁺/Ca²⁺ | 需膜去极化 + 甘氨酸/ D-丝氨酸共激动；介导 Ca²⁺内流，与 LTP 密切相关 |
| **Kainate** | GluK1-5          | Na⁺/K⁺      | 调节递质释放，参与癫痫                                |
| **mGluR**   | I/II/III 组       | G 蛋白偶联      | 调制突触强度，参与 LTD                              |

**核心概念：NMDA 受体作为“巧合检测器”**

- NMDA 受体通道被 Mg²⁺在静息电位下阻断。
- 只有当：
  1. 突触前释放谷氨酸（配体结合）
  2. 突触后膜充分去极化（解除 Mg²⁺阻断）
  
  同时发生时，Ca²⁺才能内流。
- 这正是**赫布理论**（Hebbian Learning）的分子实现：“一起放电，一起连接”。

### 4.3 GABA（γ-氨基丁酸）—— 主要抑制性递质

| 受体类型       | 离子选择性               | 作用特点                             |
| ---------- | ------------------- | -------------------------------- |
| **GABA_A** | Cl⁻通道               | 快速抑制性突触后电位（IPSP），可被苯二氮䓬、巴比妥类药物增强 |
| **GABA_B** | G 蛋白偶联，K⁺通道/ Ca²⁺通道 | 慢速抑制，参与突触前抑制和突触后超极化              |

**功能意义**：
- 抑制性神经元（Interneurons）控制神经环路的兴奋/抑制平衡。
- E/I 平衡失调与癫痫、焦虑、精神分裂症相关。
- 前额叶皮层的抑制控制是“延迟反应”“抑制冲动”的神经基础。

### 4.4 单胺类递质：情绪、动机与警觉的化学开关

#### 多巴胺（Dopamine）

| 通路      | 起点          | 终点             | 功能           |
| ------- | ----------- | -------------- | ------------ |
| 中脑边缘通路  | 腹侧被盖区 (VTA) | 伏隔核 (NAcc)、前额叶 | 奖赏、动机、目标导向行为 |
| 中脑皮质通路  | VTA         | 前额叶皮层          | 认知控制、工作记忆    |
| 黑质纹状体通路 | 黑质致密部       | 纹状体            | 运动控制         |
| 结节漏斗通路  | 下丘脑         | 垂体             | 内分泌调节        |

- 多巴胺受体：D1 家族（兴奋性 Gs）和 D2 家族（抑制性 Gi）。
- **关键区分**：多巴胺主要编码的是“奖赏预测误差”（Prediction Error），而非快乐本身。
  - 实际奖赏 > 预期 → 多巴胺增加（学习）
  - 实际奖赏 = 预期 → 基线（维持行为）
  - 实际奖赏 < 预期 → 多巴胺下降（更新预期）

#### 血清素 / 5-HT（Serotonin）

- 主要来源：中缝核（Raphe Nuclei）。
- 受体类型：14 种以上，主要是代谢型受体（5-HT1、5-HT2 等）。
- 功能：
  - 调节情绪、食欲、睡眠、攻击性
  - 影响情绪记忆巩固
  - 与社会地位、风险回避相关

#### 去甲肾上腺素（Norepinephrine, NE）

- 主要来源：蓝斑核（Locus Coeruleus）。
- 受体：α 和 β 肾上腺素受体。
- 功能：
  - 调节警觉、注意、应激反应
  - 在“战斗或逃跑”反应中增强感觉增益
  - 调节前额叶功能：低水平 NE 促进工作记忆，高水平 NE 损害前额叶、强化杏仁核

#### 乙酰胆碱（Acetylcholine, ACh）

- 主要来源：基底前脑（Basal Forebrain）、脑干。
- 受体：烟碱型（nAChR，离子型）和毒蕈碱型（mAChR，代谢型）。
- 功能：
  - 注意、学习、记忆
  - 调节皮层状态（清醒 vs 睡眠）
  - 基底前脑胆碱能系统退化与阿尔茨海默病相关

### 4.5 递质共存与共同释放

- 一个神经元可共存多种递质（如谷氨酸 + 多巴胺共同释放）。
- 递质释放取决于动作电位频率：低频可能只释放小分子递质，高频才触发神经肽释放。
- 这意味着同一个神经元在不同激活模式下可以传递不同“信息”。

## 五、细胞内信号转导

### 5.1 G 蛋白偶联受体（GPCR）信号通路

```
神经递质 + GPCR
    ↓
G 蛋白活化（Gs/Gi/Gq）
    ↓
第二信使生成：cAMP / IP₃ / DAG / Ca²⁺
    ↓
蛋白激酶活化：PKA / PKC / CaMKII
    ↓
离子通道磷酸化 → 改变兴奋性
或
转录因子活化（CREB） → 基因表达 → 长时程改变
```

### 5.2 关键第二信使

| 第二信使 | 来源      | 主要效应                  |
| ---- | ------- | --------------------- |
| cAMP | AC 活化   | 激活 PKA，调节 HCN 通道、CREB |
| IP₃  | PIP₂ 水解 | 触发内质网 Ca²⁺释放          |
| DAG  | PIP₂ 水解 | 激活 PKC                |
| Ca²⁺ | 膜通道/内质网 | 激活 CaMKII、钙调磷酸酶       |
|      |         |                       |

### 5.3 从突触活动到基因表达

- 短时记忆：仅涉及现有蛋白的修饰（如离子通道磷酸化）。
- 长时记忆：需要**新蛋白合成**和**结构改变**。
- **CREB（cAMP 反应元件结合蛋白）**是关键转录因子：
  - 被 PKA、CaMKII、MAPK 等磷酸化
  - 促进即刻早期基因（IEGs）如 c-fos、Arc 表达
  - 参与突触结构重塑

### 5.4 长期压力如何改变大脑结构

- 慢性压力 → HPA 轴持续激活 → 皮质醇/糖皮质激素升高。
- 糖皮质激素受体在杏仁核、海马、前额叶均有表达。
- 效应：
  - **海马**：树突萎缩，神经发生减少，记忆下降
  - **前额叶**：树突棘丢失，执行功能下降
  - **杏仁核**：神经元肥大，恐惧记忆增强
- 这是“认知防御”必须考虑生理状态的生物基础。

## 六、突触可塑性：LTP 与 LTD

### 6.1 赫布理论与可塑性

> “Neurons that fire together, wire together.” —— Donald Hebb

- 如果突触前和突触后神经元同时活跃，它们之间的连接会增强。
- 这是学习的细胞基础：神经环路的连接强度被经验改写。

### 6.2 长时程增强（LTP）

| 特征            | 说明                               |
| ------------- | -------------------------------- |
| 诱导            | 高频刺激（Tetanus）导致 NMDA 受体开放、Ca²⁺内流 |
| 早期 LTP（E-LTP） | 1-3 小时，依赖 CaMKII 等激酶，不涉及新蛋白合成    |
| 晚期 LTP（L-LTP） | 数小时至数天，依赖基因转录和新蛋白合成              |
| 表达机制          | AMPA 受体插入突触后膜、受体磷酸化、树突棘增大        |
| 特异性           | 输入特异性（只强化被激活的突触）                 |

**LTP 与学习的关联证据**：
- 海马可诱导 LTP 的通路参与空间记忆（Morris 水迷宫）。
- NMDA 受体拮抗剂阻断 LTP 也阻断某些学习任务。
- 但不能简单等同：LTP 是细胞机制，学习是系统层面现象。

### 6.3 长时程抑制（LTD）

| 特征     | 说明                                            |
| ------ | --------------------------------------------- |
| 诱导     | 低频刺激（1-5 Hz）或持续低水平 Ca²⁺升高                     |
| 小脑 LTD | 平行纤维 +  climbing fiber 共同激活 → 浦肯野细胞 AMPA 受体内化 |
| 海马 LTD | 依赖 NMDA 受体、蛋白磷酸酶（PP1/PP2A/Calcineurin）        |
| 功能     | 遗忘、突触权重归一化、学习新信息时清除旧连接                        |

### 6.4 稳态可塑性（Homeostatic Plasticity）

- ==神经元不能无限增强或减弱，否则会进入兴奋/抑制失衡。==
- ==稳态机制：==
  - ==突触缩放（Synaptic Scaling）==
  - ==兴奋性自我调节==
  - ==抑制性突触重塑==
- ==意义：在学习新信息的同时保持网络稳定。==

### 6.5 可塑性的时间窗口

- 经典 LTP 诱导要求突触前和突触后活动间隔在 **~40 ms** 内（STDP，Spike-Timing-Dependent Plasticity）。
- 突触前先于突触后 → 长时程增强（LTP）
- 突触后先于突触前 → 长时程抑制（LTD）
- 这一时间窗口对理解“练习时机”“重复间隔”有重要意义。

### 8.2 信号识别中的神经递质作用

- **去甲肾上腺素**：决定信号/噪声比。高警觉状态下，微弱信号被放大，但也容易误判。
- ==**乙酰胆碱**：决定注意焦点。胆碱能增强使目标信号处理增强，背景抑制。==
- ==**多巴胺**：决定信号的价值标签。同一信息在不同预期框架下被赋予不同显著性。==

### 8.3 认知防御的神经基础

- “系统 2”的抑制控制依赖**前额叶→纹状体/杏仁核**的谷氨酸/GABA 能投射。
- 训练认知防御本质上是增强这些通路的突触效率。
- 睡眠、运动、冥想等干预通过影响神经可塑性间接增强认知控制。

## 十、记忆卡片（Anki 风格）

**Q：什么是 NMDA 受体的 coincidence detection 特性？**
A：NMDA 受体需要同时满足两个条件才开放：

突触前释放谷氨酸（配体结合）+ 突触后膜充分去极化（解除 Mg²⁺阻断）。
因此它是赫布学习的分子实现。

**Q：多巴胺编码的是“快乐”吗？**
A：不是。

==多巴胺主要编码“奖赏预测误差”——实际奖赏与预期奖赏之间的差异。==



**Q：LTP 和 LTD 分别由什么刺激模式诱导？**
A：LTP 通常由高频刺激（如 100 Hz 几组）诱导；
LTD通常由低频刺激（如 1 Hz 持续）诱导。

**Q：GABA_A 和 GABA_B 受体的主要区别？**
A：GABA_A 是离子型 Cl⁻通道，介导快速抑制；GABA_B 是代谢型 GPCR，介导慢速抑制，可开放 K⁺通道或关闭 Ca²⁺通道。

**Q：CREB 在记忆巩固中起什么作用？**
==A：CREB 是被蛋白激酶磷酸化的转录因子，促进即刻早期基因表达和新蛋白合成，是长时记忆从短时记忆转化的关键分子开关。==
