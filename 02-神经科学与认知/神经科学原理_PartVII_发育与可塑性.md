# 《神经科学原理》Part VII：神经系统的发育与可塑性

> **定位**：大脑不是固定的，它在一生中都在重塑。这一部分是“政治敏感度可训练”的生物学证据。
> 
> **核心命题**：神经系统如何在发育中形成精确的连接？成年后还能改变吗？

---

## 一、章节定位与学习目标

### 1.1 为什么这一部分重要

- 发育研究揭示了大脑连接的“设计原则”。
- 可塑性研究证明了成年后大脑仍能改变。
- 这是所有训练、学习、康复的神经基础。

### 1.2 阅读目标

1. 理解神经发生、迁移、轴突导向的基本机制。
2. 掌握突触形成与活动依赖可塑性的关系。
3. 理解关键期与敏感期概念。
4. 了解成人神经发生和皮层重组的证据。
5. 将发育与可塑性与终身学习、认知训练建立联系。

## 二、神经发育

### 2.1 神经发生（Neurogenesis）

- 神经上皮细胞 → 放射状胶质细胞 → 神经元前体细胞 → 神经元。
- 主要发生在胚胎期。
- 成年期仅在少数区域发生：
  - 海马齿状回（与学习记忆相关）
  - 嗅球（啮齿类明显，人类有限）

### 2.2 神经迁移（Migration）

- 神经元从生发区沿放射状胶质细胞迁移到最终位置。
- 皮层按“由内而外”的顺序形成。
- 迁移异常导致脑回畸形、癫痫、智力障碍。

### 2.3 轴突导向（Axon Guidance）

- 生长锥（Growth Cone）是轴突末端的探索结构。
- 导向分子包括：

| 分子家族         | 作用             |
| ------------ | -------------- |
| Netrin       | 吸引或排斥（取决于受体）   |
| Slit         | 排斥（通过 Robo 受体） |
| Semaphorin   | 排斥             |
| Ephrin       | 排斥或吸引          |
| 细胞粘附分子（CAMs） | 促进轴突束化         |

- 化学吸引/排斥 + 机械引导共同决定轴突路径。

### 2.4 突触形成

- 轴突到达靶区后，与突触后结构形成连接。
- 突触形成依赖：
  - 细胞粘附分子（如 Neuroligin-Neurexin）
  - 活动依赖性信号
  - 神经营养因子

## 三、突触连接的形成与精细调节

### 3.1 早期过度连接与修剪

- 发育早期突触数量超过成年期。
- 通过活动依赖的竞争，部分突触被强化，部分被消除。
- 这一原则：“一起放电，一起连接；不一起放电，断开连接”。

### 3.2 活动依赖的可塑性

- 神经活动本身塑造神经环路。
- 视觉皮层的眼优势柱形成依赖早期视觉经验。
- 剥夺一只眼的视觉输入 → 该眼对应的皮层区域缩小，另一眼区域扩大。

### 3.3 关键期（Critical Period）

| 特征  | 说明                        |
| --- | ------------------------- |
| 定义  | 发育中经验对神经环路塑造特别有效的时期       |
| 机制  | 抑制性神经环路成熟、细胞外基质变化（如 PNNs） |
| 后果  | 关键期后可塑性下降，但并非完全关闭         |
| 例子  | 人类语言习得、双眼视觉、鸟类鸣叫学习        |

### 3.4 周围神经网络（PNNs）

- 细胞外基质结构，包裹成熟神经元。
- 限制轴突生长和突触重塑。
- 降解 PNNs 可在成年期恢复某些关键期可塑性。

## 四、皮层可塑性与成人神经发生

### 4.1 成人神经发生

- ==人类海马齿状回终生产生新神经元。==
- ==新神经元整合到现有环路中。==
- ==受以下因素调节：==
  - ==运动（增强）==
  - ==丰富环境（增强）==
  - ==压力（抑制）==
  - ==衰老（减少）==
### 4.2 皮层重组

- ==感觉皮层图谱可根据经验改变。==
- ==例如：弦乐演奏者手指对应皮层区域扩大；盲人视觉皮层参与触觉/听觉加工。==
- ==这种重组是康复训练和技能学习的神经基础。==

### 4.3 代偿性可塑性

- ==脑损伤后，未受损区域可接管部分功能。==
- ==年轻大脑代偿能力更强，但成人大脑也有一定可塑性。==
- ==这解释了为什么康复训练有效。==

## 五、可塑性的分子机制

### 5.1 结构可塑性

- ==树突棘可以增大、缩小、形成或消失。==
- ==树突棘形态与突触强度相关：==
  - ==薄棘：可塑性高，不稳定==
  - ==蘑菇棘：稳定性高，成熟突触==

### 5.2 功能可塑性

- LTP/LTD（见 Part III）。
- 突触前释放概率改变。
- 受体数量和亚型改变。

### 5.3 表观遗传与可塑性

- DNA 甲基化、组蛋白修饰调节基因表达。
- 早期经验可通过表观遗传机制产生长期影响。
- 这是“童年经历塑造政治模式”的分子基础。

## 六、关键期与终身学习

### 6.1 关键期不是终点

- 关键期后可塑性下降，但从未消失。
- ==通过特定干预（如注意力、动机、重复练习）可增强成人可塑性。==
- ==双语学习、乐器演奏、运动训练都证明成人大脑可重塑。==

### 6.2 增强可塑性的因素

| 因素        | 机制                | 实践建议          |
| --------- | ----------------- | ------------- |
| ==睡眠==    | ==突触稳态、记忆巩固==     | ==保证充足睡眠==    |
| ==运动==    | ==增加 BDNF、血流量==   | ==规律有氧运动==    |
| ==注意==    | ==增强乙酰胆碱、去甲肾上腺素== | ==专注练习==      |
| ==新奇与挑战== | ==激活多巴胺系统==       | ==适度难度的学习任务== |
| ==社交互动==  | ==激活社会脑网络==       | ==讨论、教学、合作==  |

## 八、与你关心主题的关联映射
### 8.1 童年经历塑造政治模式
- 早期社会环境通过杏仁核-前额叶环路的发育塑造威胁评估模式。
- 童年逆境导致：
  - 杏仁核反应增强
  - 前额叶调控减弱
  - HPA 轴应激反应改变
- 这些改变具有适应性（在危险环境中生存），但也导致成年后的认知偏差。
### 8.2 政治敏感度可训练的生物学证据
- 成人前额叶和杏仁核的可塑性允许通过训练改变反应模式。
- 正念、认知重评、暴露疗法都利用了神经可塑性。
- 训练需要：
  - 重复（Hebbian 可塑性）
  - 注意（增强乙酰胆碱）
  - 反馈（多巴胺预测误差）
  - 恢复（睡眠巩固）
### 8.3 认知防御的训练设计原则

| 训练目标      | 神经机制                    | 训练方法          |
| --------- | ----------------------- | ------------- |
| 降低杏仁核过度反应 | 杏仁核 habituation，前额叶抑制增强 | 渐进暴露、正念       |
| 增强前额叶控制   | 前额叶-纹状体/杏仁突触强化          | 工作记忆训练、延迟反应练习 |
| 改善模式识别    | 皮层可塑性、树突棘重塑             | 案例分析、多角度练习    |
| 情绪调节      | 岛叶-ACC 重评               | 认知重评训练        |
| 压力恢复      | HPA 轴调节、海马神经发生          | 运动、睡眠、社交      |
### 8.4 可塑性的限制
- 可塑性不是无限的，受遗传、年龄、健康状态影响。
- 旧连接不会完全消失，新连接需要与之竞争。
- 改变需要时间，不能一蹴而就。

## 十、记忆卡片（Anki 风格）

**Q：什么是神经系统的关键期？**
A：发育中经验对神经环路塑造特别有效的时期。关键期后某些可塑性下降，但不会完全关闭。

**Q：轴突导向的主要分子有哪些？**
A：Netrin（吸引/排斥）、Slit（排斥）、Semaphorin（排斥）、Ephrin（吸引/排斥）。

**Q：成人大脑中哪里还有神经发生？**
A：主要是海马齿状回。嗅球在啮齿类明显，人类较有限。

**Q：周围神经网络（PNNs）有什么作用？**
A：PNNs 是包裹成熟神经元的细胞外基质结构，限制轴突生长和突触重塑，是成年可塑性下降的机制之一。

**Q：==哪些因素可以增强成人大脑可塑性？**==
==A：睡眠、运动（增加BDNF）、注意、新奇挑战、社交互动。==
