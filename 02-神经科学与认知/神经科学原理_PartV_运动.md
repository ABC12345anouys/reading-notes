# 《神经科学原理》Part V：运动（Movement）

> **定位**：意愿如何转化为行动。运动系统与决策执行、习惯形成、身体控制直接相关。
> 
> **核心命题**：大脑如何将抽象意图转化为精确、协调的肌肉收缩？

---

## 一、章节定位与学习目标

### 1.1 为什么运动系统值得理解

- “知道但做不到”是认知防御中的常见问题：理解运动控制有助于理解执行失败。
- 运动系统与决策系统共享基底神经节、小脑等结构。
- 习惯的形成与自动化行为依赖于运动环路。

### 1.2 阅读目标

1. 理解脊髓反射和中枢模式发生器。
2. 掌握随意运动控制的主要脑区及其功能。
3. 理解运动皮层、小脑、基底神经节的协作关系。
4. 了解眼动控制的神经机制。
5. 将运动系统与执行控制、习惯养成建立联系。

---

## 二、运动系统概览

```
运动意图
    ↓
大脑皮层（运动计划）
    ↓
脑干（运动协调/姿势控制）
    ↓
脊髓（运动执行/反射整合）
    ↓
运动神经元 → 肌肉收缩
```

- 上运动神经元：皮层和脑干中的运动神经元。
- 下运动神经元：脊髓和脑干运动核中的运动神经元，直接支配肌肉。

---

## 三、脊髓反射与模式发生

### 3.1 反射弧

最简单的反射弧：

```
感觉受体 → 感觉神经元 → 脊髓中间神经元 → 运动神经元 → 肌肉
```

- 反射是快速、自动化的保护机制。
- 临床意义：深腱反射检查可评估脊髓和外周神经功能。

### 3.2 牵张反射

| 成分 | 功能 |
|------|------|
| 肌梭 | 检测肌肉长度变化 |
| Ia 传入纤维 | 快速传递牵张信息 |
| α 运动神经元 | 引起被牵拉肌肉收缩 |
| γ 运动神经元 | 调节肌梭敏感性 |

- 牵张反射是姿势维持和肌张力调节的基础。

### 3.3 交互抑制

- 屈肌收缩时，伸肌被抑制；反之亦然。
- 由抑制性中间神经元实现。
- 保证运动的协调性和效率。

### 3.4 中枢模式发生器（CPG）

- 脊髓和脑干中的神经环路能产生节律性运动模式。
- 不需要大脑皮层持续输入。
- 例如：行走、游泳、呼吸、咀嚼。
- CPG 可被高级中枢调制，但不能被完全替代。

## 四、随意运动控制

### 4.1 初级运动皮层（M1）

- 位于额叶中央前回。
- 以**躯体拓扑方式**组织，形成“运动小人图”。
- 运动皮层神经元编码：
  - 运动方向
  - 力量
  - 运动轨迹
  - 终极目标（逐渐被认为是主要编码对象）

### 4.2 运动前区与辅助运动区

| 区域 | 功能 |
|------|------|
| 运动前区（Premotor） | 运动准备、感觉-运动转换、动作模仿 |
| 辅助运动区（SMA） | 动作序列规划、双侧协调、内部触发动作 |

### 4.3 顶叶-运动皮层环路

- 顶叶提供空间信息和动作目标。
- 背侧视觉通路（Where/How）直接为运动系统服务。
- 这解释了为什么动作引导依赖于对目标空间属性的感知。

### 4.4 皮质脊髓束

- 从大脑皮层到脊髓的主要下行通路。
- 约 85-90% 纤维在延髓锥体交叉到对侧。
- 控制精细随意运动，尤其是手和面部。

## 五、小脑

### 5.1 小脑的功能

- **运动协调**：协调多关节运动的时间和幅度。
- **运动学习**：特别是误差校正（如前庭-眼反射、投掷技能）。
- **预测**：预测动作感觉后果，实现平滑运动。
- **认知/情绪功能**：近年研究发现小脑也参与某些认知和情绪加工。

### 5.2 小脑的内部结构

| 结构 | 功能 |
|------|------|
| 浦肯野细胞 | 小脑皮层唯一输出神经元，抑制性 |
| 颗粒细胞 | 最丰富的兴奋性神经元，扩增输入 |
| 爬行纤维 | 来自下橄榄核，传递误差信号，诱导 LTD |
| 苔藓纤维 | 来自脊髓和前庭核，传递感觉/运动信息 |

### 5.3 小脑与运动学习

- 小脑浦肯野细胞的可塑性（LTD）是运动学习的基础。
- 当实际动作结果与预期不符时，爬行纤维提供误差信号。
- 这类似于机器学习中的“误差反向传播”。

### 5.4 小脑损伤

- 共济失调（Ataxia）：运动不协调、步态不稳。
- 意向性震颤：动作越接近目标越明显。
-  dysmetria：动作幅度判断失误。
- 不是瘫痪，而是运动的质量问题。

## 六、基底神经节

### 6.1 基底神经节的组成

| 结构 | 主要功能 |
|------|---------|
| 纹状体（尾状核+壳核） | 主要输入核团，接收皮层和丘脑输入 |
| 苍白球（内/外侧） | 主要输出核团 |
| 黑质致密部（SNc） | 多巴胺能神经元，调控纹状体 |
| 黑质网状部（SNr）/ 苍白球内侧（GPi） | 输出核团，抑制丘脑 |
| 丘脑底核（STN） | 超直接通路，快速制动 |

### 6.2 基底神经节的三条通路

| 通路 | 连接 | 功能 |
|------|------|------|
| 直接通路 | 皮层 → 纹状体 → GPi/SNr → 丘脑 → 皮层 | 促进期望动作 |
| 间接通路 | 皮层 → 纹状体 → GPe → STN → GPi/SNr | 抑制竞争动作 |
| 超直接通路 | 皮层 → STN → GPi/SNr | 快速全局抑制 |

### 6.3 多巴胺的作用

- 多巴胺增强直接通路、抑制间接通路。
- 促进动作启动和奖赏学习。
- 帕金森病：黑质多巴胺神经元退化 → 运动迟缓、启动困难。
- 亨廷顿病：纹状体神经元变性 → 不自主运动。

### 6.4 基底神经节与习惯

- 基底神经节是习惯形成的关键结构。
- 习惯：刺激-反应自动化联结，不依赖目标表征。
- 这解释了为什么某些行为模式难以改变：它们已被“编译”到基底神经节中。

## 七、眼动与凝视

### 7.1 主要眼动类型

| 类型 | 功能 | 控制脑区 |
|------|------|---------|
| 扫视（Saccade） | 快速转移注视点 | 额眼区、上丘、脑干 |
| 平滑追踪 | 跟踪移动目标 | 皮层 MT/MST、脑干 |
| 前庭-眼反射（VOR） | 头部运动时稳定视网膜像 | 前庭核、小脑 |
| 注视（Fixation） | 维持视线稳定 | 上丘、脑干 |

### 7.2 上丘

- 中脑结构，接收视觉、听觉、躯体感觉输入。
- 参与注意定向和眼动触发。
- 与额眼区（FEF）协同工作。

### 7.3 眼动的认知意义

- 眼动模式反映注意分配和信息搜索策略。
- 在阅读、决策、社会互动中，眼动是认知过程的窗口。
- 训练注意和抑制冲动可以从眼动控制入手。

## 九、与你关心主题的关联映射

### 9.1 “知道但做不到”的神经基础

- 前额叶知道正确选择，但基底神经节的习惯系统仍执行旧行为。
- 这解释了为什么改变政治立场或行为模式如此困难。
- 改变习惯需要重复新行为，建立新的刺激-反应联结。

### 9.2 运动系统与决策

- 基底神经节参与行动选择（Go/No-Go）。
- 多巴胺系统调制选择动机。
- 决策不只是“想”，也是“行动准备”。

### 9.3 习惯化与政治行为

- 政治偏好和投票行为部分 habitual。
- 政党认同、媒体消费习惯可能基底神经节化。
- 改变需要打破旧习惯并建立新习惯。

### 9.4 眼动与信息搜索

- 眼动轨迹反映注意策略和偏见。
- 识别他人眼动可帮助判断其关注点和可能的意图。
- 控制自己眼动是控制注意的第一步。

## 十一、记忆卡片（Anki 风格）

**Q：什么是中枢模式发生器（CPG）？**
A：脊髓或脑干中能产生节律性运动模式的神经环路，不需要高级中枢持续输入，如行走、呼吸。

**Q：小脑的主要功能是什么？**
A：运动协调、运动学习（误差校正）、动作预测。损伤导致共济失调、意向性震颤和动作幅度失调。

**Q：基底神经节的直接通路和间接通路分别促进还是抑制动作？**
A：直接通路促进期望动作；间接通路抑制竞争动作；超直接通路提供快速全局抑制。

**Q：帕金森病的核心神经机制是什么？**
A：黑质致密部多巴胺能神经元退化，导致直接通路活性相对降低、间接通路活性相对增强，运动启动困难。

**Q：前庭-眼反射（VOR）的功能是什么？**
A：在头部运动时通过反向眼动稳定视网膜上的图像，保证视觉清晰。
