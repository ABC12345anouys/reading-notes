# 《神经科学原理》Part VIII：学习、记忆、语言与认知

> **定位**：高级认知功能的神经基础。这是“系统 2”、认知控制、政治判断的硬件说明。
> 
> **核心命题**：学习如何在大脑中留下持久改变？工作记忆如何支持复杂思维？语言与认知如何组织？

---

## 一、章节定位与学习目标

### 1.1 为什么这一部分是认知核心

- 学习记忆是所有训练的基础。
- 工作记忆是“系统 2”的核心容量。
- 前额叶皮层是执行控制、抽象思维、社会判断的关键。

### 1.2 阅读目标

1. 区分陈述性记忆与非陈述性记忆。
2. 掌握记忆的分子机制（CREB、蛋白合成、巩固）。
3. 理解海马体在陈述性记忆中的作用。
4. 掌握前额叶与工作记忆、执行功能的关系。
5. 了解语言网络的脑区组织。

## 二、学习与记忆概述

### 2.1 记忆的分类

```
记忆
├── 陈述性记忆（外显记忆）
│   ├── 情景记忆：个人经历，时间地点
│   └── 语义记忆：事实、概念、知识
└── 非陈述性记忆（内隐记忆）
    ├── 程序性记忆：技能、习惯
    ├── 启动效应：先前经验影响后续加工
    ├── 条件反射：经典/操作性
    └── 非联想学习：习惯化、敏感化
```

### 2.2 记忆的时间阶段

| 阶段        | 时长    | 特征         |
| --------- | ----- | ---------- |
| 感觉记忆      | 毫秒至数秒 | 感觉通道的短暂保持  |
| 短时记忆/工作记忆 | 秒至分钟  | 有限容量，可主动维持 |
| 长时记忆      | 分钟至终身 | 理论上容量无限    |
### 2.3 记忆巩固
- ==**巩固（Consolidation）**：记忆从易损状态转变为稳定长时记忆的过程。==
- ==**突触巩固**：数分钟至数小时，依赖蛋白合成。==
- ==**系统巩固**：数周至数年，海马与皮层之间记忆表征的重组。==
- ==睡眠在系统巩固中起关键作用。==

## 三、记忆的分子机制

### 3.1 从短时记忆到长时记忆

| 记忆类型 | 分子事件                | 是否需要新蛋白合成 |
| ---- | ------------------- | --------- |
| 短时记忆 | 离子通道磷酸化、cAMP、PKA 激活 | 否         |
| 长时记忆 | 基因转录、新蛋白合成、结构改变     | 是         |

### 3.2 CREB 与长时记忆

- **CREB（cAMP Response Element-Binding Protein）**：关键转录因子。
- 被 PKA、CaMKII、MAPK 等磷酸化后激活。
- 促进即刻早期基因（IEGs）表达：c-fos、Arc、BDNF 等。
- CREB 是长时记忆形成的“分子开关”。

### 3.3 蛋白合成抑制剂实验

- 训练后立即给予蛋白合成抑制剂（如茴香霉素）→ 阻断长时记忆，但不影响短时记忆。
- 直接证明长时记忆需要新蛋白合成。

### 3.4 记忆再巩固

- 记忆提取后进入短暂不稳定状态，需要重新巩固。
- 再巩固期间记忆可被修改或削弱。
- 这是创伤治疗和错误记忆修正的理论基础。

## 四、海马体与陈述性记忆

### 4.1 海马的结构

| 区域 | 功能 |
|------|------|
| 齿状回（DG） | 模式分离，减少输入重叠 |
| CA3 | 模式完成，自动联想记忆 |
| CA1 | 输出至皮层，时间序列编码 |
| 内嗅皮层 | 提供空间/情景信息网格细胞 |

### 4.2 海马的功能
- **陈述性记忆编码**：将日常经验转化为可提取的记忆。
- **空间记忆**：环境地图、导航。
- **情景记忆**：时间、地点、事件整合。
- **模式分离与模式完成**：区分相似经历 vs 从部分线索提取完整记忆。

### 4.3 H.M. 病例的启示

- 双侧海马切除后：
  - 无法形成新的陈述性记忆（顺行性遗忘）
  - 术前记忆部分保留（逆行性遗忘有限）
  - 程序性记忆和运动学习保留
- 结论：海马对陈述性记忆至关重要，但非陈述性记忆依赖其他系统。

### 4.4 位置细胞与网格细胞

- **位置细胞（Place Cells）**：海马神经元对特定空间位置反应。
- **网格细胞（Grid Cells）**：内嗅皮层神经元形成六边形空间网格。
- 这些发现支持海马作为“认知地图”的理论。

## 五、前额叶与工作记忆

### 5.1 前额叶皮层分区

| 分区            | 主要功能             |
| ------------- | ---------------- |
| 背外侧前额叶（dlPFC） | 工作记忆、认知控制、抽象推理   |
| 腹外侧前额叶（vlPFC） | 注意选择、反应抑制        |
| 内侧前额叶（mPFC）   | 自我相关加工、社会认知、情绪调节 |
| 眶额叶（OFC）      | 价值评估、决策          |

### 5.2 工作记忆

- **定义**：对信息进行短暂保持和主动操控的认知系统。
- **容量**：约 4±1 个组块（现代估计）。
- **维持机制**：
  - 神经元持续放电
  - 突触强化（短时可塑性）
  - 前额叶-顶叶网络协调

### 5.3 前额叶与认知控制

| 功能   | 神经基础          |
| ---- | ------------- |
| 抑制控制 | 右侧额下回/腹外侧 PFC |
| 任务切换 | 背外侧 PFC、前扣带   |
| 冲突监控 | 前扣带皮层（ACC）    |
| 延迟满足 | 腹内侧 PFC、纹状体   |
| 计划   | 背外侧 PFC       |

### 5.4 前额叶与系统 2

- Kahneman 的“系统 2”（慢思考）很大程度上对应前额叶功能。
- 前额叶实现：
  - 抽象表征
  - 假设检验
  - 反事实推理
  - 长期目标导向行为
- 前额叶功能受压力、疲劳、情绪影响。

## 六、语言与认知

### 6.1 语言网络

| 脑区                 | 功能                    | 损伤后果                    |
| ------------------ | --------------------- | ----------------------- |
| Broca 区（左额下回）      | 语言产生、语法加工             | Broca 失语：表达困难，理解相对保留    |
| Wernicke 区（左颞上回后部） | 语言理解                  | Wernicke 失语：流利但无意义，理解障碍 |
| 弓状束                | 连接 Broca 与 Wernicke 区 | 传导性失语：复述困难              |
| 角回                 | 书面语言与语义整合             | 失读症、失写症                 |
### 6.2 语言的神经模型
- **Wernicke-Lichtheim 模型**：听觉输入 → Wernicke 区 → 概念中心 → Broca 区 → 口语输出。
- 现代观点：语言加工涉及分布式网络，不仅限于 Broca/Wernicke 区。
- 语言偏侧化：约 95% 右利手者语言优势半球在左脑。
### 6.3 语言与思维
- 语言是否是思维的前提？存在争论。
- 证据：
  - 无语言能力的婴儿和动物有复杂认知。
  - 某些抽象思维可能独立于语言。
  - 但语言显著增强工作记忆和概念组合能力。

## 八、与你关心主题的关联映射

### 8.1 政治判断的神经基础

| 认知过程 | 依赖脑区/系统           | 政治意义        |
| ---- | ----------------- | ----------- |
| 信息保持 | 工作记忆/前额叶          | 同时比较多个论点    |
| 抑制偏见 | 右侧额下回/前扣带         | 抵抗第一印象和情绪冲动 |
| 价值评估 | 眶额叶/杏仁核/纹状体       | 判断政策利弊      |
| 情景记忆 | 海马                | 提取历史经验和类比   |
| 语言加工 | Broca/Wernicke 网络 | 理解论证和修辞     |
### 8.2 记忆操纵与认知防御
- 错误信息在最初编码时可能与真实记忆混淆。
- 记忆再巩固期间易受修改。
- 重复暴露谎言可增加其“熟悉感”，使其更易被接受（虚幻真相效应）。
- 防御策略：
  - 主动提取真实信息
  - 在再巩固窗口期提供更正信息
  - 培养元认知，质疑记忆来源
### 8.3 工作记忆容量与决策质量
- 工作记忆容量有限，复杂问题需要外部化（写下来、画图、列表）。
- 压力下工作记忆受损，决策更依赖启发式和情绪。
- 训练工作记忆可能提升某些认知任务表现，但迁移效果有争议。
### 8.4 睡眠与记忆巩固
- 睡眠中海马与皮层重放日间经历。
- NREM 睡眠促进陈述性记忆巩固。
- REM 睡眠可能促进情绪记忆加工和模式整合。
- 睡眠不足损害记忆巩固和前额叶功能。

## 十、记忆卡片（Anki 风格）

**Q：陈述性记忆和非陈述性记忆的区别？**
A：陈述性记忆是有意识的，包括情景记忆和语义记忆，依赖海马；非陈述性记忆是无意识的，包括程序性记忆、条件反射等，依赖纹状体、小脑、杏仁核等。

**Q：海马损伤（如 H.M.）会导致什么记忆缺陷？**
A：顺行性陈述性记忆丧失，无法形成新的事实和情节记忆；但程序性记忆和运动学习保留。

**Q：CREB 在记忆中的作用是什么？**
A：CREB 是被蛋白激酶磷酸化的转录因子，促进即刻早期基因表达和新蛋白合成，是长时记忆形成的分子开关。

**Q：==背外侧前额叶（dlPFC）的主要功能是什么？**==
==A：工作记忆、认知控制、抽象推理和计划。==

**Q：Broca 区和 Wernicke 区损伤分别导致什么失语？**
A：Broca 区损伤导致表达性失语（说话困难，理解相对保留）；Wernicke 区损伤导致感受性失语（流利但无意义，理解障碍）。
